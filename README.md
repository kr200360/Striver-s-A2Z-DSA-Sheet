# Striver's A2Z DSA Sheet

Learn data structures and algorithms in a clear sequence, from programming foundations to advanced problems. Build your coding interview skills through independent practice, better approaches, and regular revision.

## 📅 Daily DSA Consistency Tracker

This repository is maintained with a **daily DSA practice habit**. Each day's progress is committed to GitHub to build consistency, track streaks, and stay accountable.

### How I Maintain Consistency
- **Solve at least one problem every day** and commit the solution.
- **Follow Striver's A2Z sheet order** — no skipping ahead for the sake of streaks.
- **Commit daily**, even if it's a revision, a brute-force attempt, or notes on a better approach.
- **Write short notes** with each solution: intuition, time complexity, space complexity, and edge cases.
- **Revise weekly** — revisit older problems instead of only chasing new ones.
- **Track the streak** in the tables below.
